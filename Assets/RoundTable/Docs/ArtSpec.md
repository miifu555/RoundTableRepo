# Round Table — アート入稿仕様

数値の正は `Assets/RoundTable/Scripts/Data/ArtSizes.cs`。画面基準解像度は **1920 × 1080**（16:9固定）。

---

## 1. 必要なピクセル数（早見表）

| 用途 | ピクセル数 | 比率 | 枚数 | 置き場所（ファイル名） |
|---|---|---|---|---|
| **カードのイラスト** | **440 × 330** | 4:3 | **59** | `Art/CardArt/{カードID}.png` |
| カード全体（枠ごと自作・任意） | 500 × 700 | 5:7 | 59 | `Art/CardFull/{カードID}.png` |
| キャラ立ち絵 | 512 × 768 | 2:3 | 11 | `Art/Portrait/{デッキID}.png` |
| キャラ顔アイコン | 256 × 256 | 1:1 | 11 | `Art/Portrait/{デッキID}_icon.png` |
| カード裏面 | 500 × 700 | 5:7 | 1 | `Art/Common/card_back.png` |
| 対戦背景 | 1920 × 1080 | 16:9 | 1 | `Art/Common/bg_battle.png` |
| タイトル/デッキ選択背景 | 1920 × 1080 | 16:9 | 1 | `Art/Common/bg_title.png` |
| ^^（だお）獲得済み | 96 × 96 | 1:1 | 1 | `Art/Common/dao_on.png` |
| ^^（だお）未獲得 | 96 × 96 | 1:1 | 1 | `Art/Common/dao_off.png` |

合計 **85 ファイル**（CardFull を使わない場合）。
最低限これだけで見た目が完成するのは **カードイラスト 59 枚** です。

> フォルダのパスはすべて `Assets/RoundTable/` からの相対です。
> `Art/Ui/` は UI 用に自動生成された素材なので触らないでください。

## 2. 絵の入れ方

1. 上の表のフォルダに、決められたファイル名で PNG を置く
2. Unity メニュー **「Round Table / イラストを一括割り当て」** を実行
3. **「Round Table / 割り当て状況を確認」** で未設定のものが一覧できる

1枚ずつ手で入れたい場合は、カードのプレハブ（`Prefabs/Cards/{デッキID}/{カードID}.prefab`）を選んで
Inspector の **Card Data → Illustration** にドラッグしても同じです。

絵が無いスロットには「必要なサイズとファイル名」を書いたプレースホルダが出るので、
ゲームを動かしながら1枚ずつ差し替えられます。

## 3. カードの内部レイアウト

カード原寸 500 × 700 px の中で、イラストが入る窓は次の位置です（左上原点）。

```
┌─────────────────────────────┐  0
│ ●コスト   カード名           │  ← ヘッダー 0〜130
├─────────────────────────────┤  140
│                             │
│     イラスト 440 × 330      │  ← x=30, y=140
│                             │
├─────────────────────────────┤  470
│      攻撃 / フィールド       │  ← ジャンル帯 482〜526
├─────────────────────────────┤
│ 効果テキスト                 │  ← 538〜678
└─────────────────────────────┘  700
```

画面上の表示幅は 手札 190px / 場 132px / 拡大 430px / 相手の手札(裏) 62px。
原寸 500px が最大表示(430px)より大きいので、拡大してもぼけません。

場のフィールドカードだけは別レイアウト（Compact）で描かれます。
小さくても名前が読めるよう、コストとイラストと名前だけを大きめに配置したものです。
プレハブの `Compact` 以下を編集すれば見た目を変えられます。

## 4. Unity のインポート設定

「一括割り当て」を実行すると自動で Sprite に変換されます。手で設定する場合は:

- **Texture Type**: `Sprite (2D and UI)`
- **Sprite Mode**: `Single` / **Mesh Type**: `Full Rect`
- ドット絵にする場合のみ **Filter Mode** = `Point` / **Compression** = `None`

## 6. カード名について

仕様書で名前が確定していたのは **連休の始まり / 爆弾発言 / 反抗心 / 古武術** の4枚だけなので、
残りは仮称です。カードのプレハブを選んで Inspector の **Card Data → Display Name** を
書き換えれば反映されます（ファイル名 = カードID は変わりません）。
